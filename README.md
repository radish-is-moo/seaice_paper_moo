# Sea-ice forecast diagnostics

## Current research package

Download [seaice-forecast-diagnostics.zip](seaice-forecast-diagnostics.zip) for the updated 2023–2025 ver2 code, trained model checkpoints, normalization statistics, figure inputs, and masks. This ZIP supersedes the earlier extracted folder for release preparation.

[Versioned research data release](https://github.com/radish-is-moo/seaice_paper_moo/releases/tag/ver2-data-v1.0.0) provides the forecast/reference archives and evaluation context. Check archive_manifest.json for SHA-256 hashes. Raw PIOMAS/ERA5 training data remain available from their original providers; full training histories are not bundled. No code license has yet been assigned.
